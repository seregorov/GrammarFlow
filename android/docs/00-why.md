# Зачем GrammarFlow на Android

## Проблема

На Windows GrammarFlow решает задачу **без смены контекста**: скопировал текст → **Alt+C** → исправил → вставил обратно.

На телефоне сценарий «открой отдельное приложение → вставь текст → скопируй результат» — это **3–5 жестов и потеря фокуса**. Так живут редко используемые утилиты, не ежедневный инструмент.

## Решение

**Своя клавиатура (IME)** с панелью действий над клавишами:

- **Исправить** — орфография, пунктуация, грамматика
- **Варианты** — стилистические переписывания (formal / concise / creative)

Пользователь правит текст **в том же поле**, где печатает (Telegram, почта, заметки). Это ближайший аналог Alt+C на мобильном.

## Почему не «порт десктопа»

| Десктоп | Android |
|---------|---------|
| Глобальный Alt+C (`pynput`) | Нет произвольных глобальных хоткеев |
| Bubble поверх экрана | Только overlay с `SYSTEM_ALERT_WINDOW` |
| System tray | Foreground service / notification |
| Буфер из фона | Clipboard с Android 10+ сильно ограничен |
| PySide6 | Нативный Kotlin + IME |

Android-клиент — **новое приложение** с тем же AI-ядром, другим жестом.

## Второй вход: Process Text

Для пользователей, которые не хотят менять клавиатуру: выделил текст → «Исправить (GrammarFlow)» в системном меню. Дополнение к IME, не замена.

## Ценность для пользователя

- Быстрая правка опечаток в чате
- Улучшение формулировок без копипасты
- Русский язык через YandexGPT Lite (как на десктопе)

## Что не является целью v1

- Замена Gboard полностью (свайп, голос, эмодзи-клавиатура)
- Floating bubble как на Windows
- Офлайн-режим без интернета
