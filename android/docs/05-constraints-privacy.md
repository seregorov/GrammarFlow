# Ограничения Android и Privacy

## Ограничения платформы

### IME (InputMethodService)

- Работает только когда пользователь **выбрал** эту клавиатуру.
- Замена текста через `InputConnection` — надёжно в стандартных `EditText`; в **WebView** и кастомных редакторах бывают сбои.
- Нельзя «подслушивать» другие приложения вне активной сессии ввода.

### Clipboard

- С Android 10+ приложения в **фоне** не видят clipboard.
- Не строить продукт на «прочитать буфер при Alt+C» — на Android это не работает как на Windows.

### Overlay / Bubble

- `SYSTEM_ALERT_WINDOW` — отдельное разрешение, негатив UX, риск отклонения в Play.
- **Не в MVP** — см. [00-why.md](00-why.md).

### Process Text

- Не все host-приложения экспортируют Process Text.
- Share intent — более универсален, но длиннее по жестам.

### Сеть

- IME должен корректно показывать offline (нет API без интернета).
- TLS обязателен; certificate pinning — опционально позже.

## Privacy (принципы)

GrammarFlow Keyboard — **категория IME**. Google Play и пользователи чувствительны к клавиатурам.

### Что обещаем пользователю

1. **Текст отправляется на Yandex AI Studio только** когда пользователь нажал **Исправить** или **Варианты**.
2. **Нажатия клавиш не логируются** и не отправляются на сервер.
3. **API-ключ** хранится локально в зашифрованном хранилище, не в облаке GrammarFlow (нет своего бэкенда в MVP).
4. В настройках — ссылка на политику конфиденциальности и возможность **удалить ключи**.

### Что писать в Play Console

- Тип данных: пользовательский контент (текст по запросу)
- Цель: исправление/улучшение текста через LLM
- Передача третьим лицам: Yandex Cloud (Foundation Models API)
- Data safety: «Collected on demand», not «always on»

### Чего не делать

- Analytics на содержимое сообщений
- Crash reports с полным текстом поля ввода
- Фоновая синхронизация текста

## Безопасность секретов

| Десктоп | Android |
|---------|---------|
| `.env` локально | EncryptedSharedPreferences |
| Не коммитить | Не в APK literals; не в git |
| Folder ID + API Key | Те же переменные, другой storage |

Рекомендация: отдельный API-ключ сервисного аккаунта для мобильного клиента с минимальными ролями (`ai.languageModels.user`).

## Соответствие десктопу

- Та же модель и endpoint — единый биллинг/квоты в Yandex Cloud.
- Промпты идентичны — предсказуемое качество correct/improve.

## Риски

| Риск | Митигация |
|------|-----------|
| Пользователь не включит IME | Онбординг + ProcessText fallback |
| Play отклонит IME без privacy | Явная политика, data safety form |
| Плохая замена текста в app X | Документировать known issues; тестировать Telegram, Gmail, Chrome |
| 401 от Yandex | Экран настроек + проверка ключей |
